Lets define some settings for this tutorial.

1.4 Settings

adt.comp <- c(1:18) # components used from the dimension redcution of the Protein modality
prop.annotated.cells <- 0.5 # proportion of cell label to keep to illsutrate the semi-superveised workflow  (see below)

2 Single cell preprocessing

2.1 Dimension reductions

Before identifying metacells we have to preprocess the single cell data. This includes data normalization and dimension reduction of each modality. For this we can follow a standard Seurat workflow.

DefaultAssay(bm) <- 'ADT'
VariableFeatures(bm) <- rownames(bm[["ADT"]])
bm <- NormalizeData(bm, normalization.method = 'CLR', margin = 2) %>% 
  ScaleData() %>% RunPCA(reduction.name = 'apca')

DefaultAssay(bm) <- "RNA"
bm <- NormalizeData(bm,normalization.method = "LogNormalize",assay = "RNA") %>% FindVariableFeatures() %>% ScaleData() %>% RunPCA()

2.2 Single-cell multimodal integration

Based on this dimension reductions we can integrate protein and RNA modalities together using the WNN approach from Seurat. This step is not required for metacell identification but we will use the single-cell final UMAP embedding to visually assess metacell quality.


bm <- FindMultiModalNeighbors(
  bm, 
  reduction.list = list("pca", "apca"), 
  dims.list = list(rna.comp, adt.comp), 
  modality.weight.name = "RNA.weight")

bm <- RunUMAP(bm, nn.name = "weighted.nn", reduction.name = "wnn.umap", reduction.key = "wnnUMAP_")

DimPlot(bm,reduction = "wnn.umap", group.by = 'celltype.l1')

DimPlot(bm,reduction = "wnn.umap", group.by = 'celltype.l2')

3 Metacell identification with SuperCell2.0

3.1 Unsupervised multimodal metacell identification

We can identify metacells based on protein and RNA modalities.

bm.mc.multi <- SCimplify_for_Seurat(
  bm, 
  assay = c("RNA","ADT"),
  reduction = list("pca", "apca"), 
  dims = list(rna.comp, adt.comp), 
  gamma = graining.level
)
#> RNA ADT

SCimply_for_Seurat function gives a seurat metacell object with aggregated (summed) raw counts for each modality. All categorical metadata available in the single cell seurat object are also aggregated in the resulting metacell object by assigning the metacell to the label with the maximum absolute abundance within it.

3.3 Semi-supervised metacell identifications

SuperCell2.0 can leverage prior knowledge of the cell type in the form of a partial annotation in order to help metacell identification.

To illustrate this feature we can create a new annotation by hiding a certain amount of cell type labels.

prop.to.hide <- 0.5
bm[["partial_annotation"]] <- bm[["celltype.l2"]]

cells.to.hide <- sample(colnames(bm),
                        size = as.integer(prop.to.hide * ncol(bm) ))

bm[["partial_annotation"]][cells.to.hide,] <- NA

We can now use the semi-supervised multimodal workflow

bm.mc.multi.sup <- SCimplify_for_Seurat(
  bm, 
  assay = c("RNA","ADT"),
  reduction = list("pca", "apca"), 
  dims = list(rna.comp, adt.comp), 
  gamma = graining.level,
  label = "partial_annotation"
)


cov.multi.sup <- DimPlotSC(bm,
                           bm.mc.multi,

                           metacell.col = "celltype.l2")

3.4 Comparison of metacell workflows

We can evaluate the different metacells workflows based on metacell purities with respect to the original single-cell annotation.

bm.mc.multi$workflow <- "unsup_multi"
bm.mc.multi.sup$workflow <- "semisup_multi"
bm.mc.rna$workflow <- "unsup_RNA"
bm.mc.rna.sup$workflow <- "semisup_RNA"

purity_results <- rbind(FetchData(bm.mc.multi,c("celltype.l2_purity","workflow")),
                        FetchData(bm.mc.multi.sup,c("celltype.l2_purity","workflow")),
                        FetchData(bm.mc.rna,c("celltype.l2_purity","workflow")),
                        FetchData(bm.mc.rna.sup,c("celltype.l2_purity","workflow")))

purity_results$workflow <- factor(purity_results$workflow,levels = c("semisup_multi",
                                                                     "unsup_multi",
                                                                     "semisup_RNA",
                                                                     "unsup_RNA"))

ggplot(purity_results,aes(x= workflow,y = celltype.l2_purity,fill = workflow)) + 
  geom_boxplot() + 
  theme_bw()

Multimodal workflow outperforms RNA-based workflow and semi-supervision using partial annotation improve metacell quality.

3.5 Rescaling

A metacell object can be rescaled to another graining level, without re-identifying metacells.

bm.mc.multi <- SCimplify_for_Seurat(seurat = bm,seurat.mc = bm.mc.multi,gamma = 20)

4 Metacell downstream analysis

We can use the metacells for faster and lighter downstream analysis.

4.1 Dimention reduction and multimodal embeddings of metacells

We use the same workflow as for single cells with first dimension reductions specific to each modality.

DefaultAssay(bm.mc.multi) <- 'ADT'
VariableFeatures(bm.mc.multi) <- rownames(bm.mc.multi[["ADT"]])
bm.mc.multi <- NormalizeData(bm.mc.multi, normalization.method = 'CLR', margin = 2) %>% 
  ScaleData() %>% RunPCA(reduction.name = 'apca')

DefaultAssay(bm.mc.multi) <- "RNA"
bm.mc.multi <- NormalizeData(bm.mc.multi,normalization.method = "LogNormalize",assay = "RNA") %>% FindVariableFeatures() %>% ScaleData() %>% RunPCA()

Then we perform a multimodal integration of the metacells thanks to the WNN approach.

bm.mc.multi <- FindMultiModalNeighbors(
  bm.mc.multi, 
  reduction.list = list("pca", "apca"), 
  dims.list = list(rna.comp, adt.comp), 
  modality.weight.name = "RNA.weight")

bm.mc.multi <- RunUMAP(bm.mc.multi, nn.name = "weighted.nn", reduction.name = "wnn.umap", reduction.key = "wnnUMAP_")

DimPlot(bm.mc.multi,reduction = "wnn.umap", group.by = 'celltype.l1')

DimPlot(bm.mc.multi,reduction = "wnn.umap", group.by = 'celltype.l2')

We can cluster metacells based on the WNN graph.

bm.mc.multi <- FindClusters(bm.mc.multi,graph.name = "wsnn")

4.2 Visualization

SuperCell2.0 provides a set of functions to visualize metacell data.

DimPlot.Supercell function can be used to display metacell size in Seurat dimension plots.

DimPlot.SuperCell(bm.mc.multi,reduction = "wnn.umap", group.by = 'celltype.l1')

DimPlot.SuperCell(bm.mc.multi,reduction = "wnn.umap", group.by = 'celltype.l2')

DimPlot.SuperCell(bm.mc.multi,reduction = "wnn.umap") + ggtitle("Metacell clusters")

VlnPlot.Supercell function can be used for plotting violin plot weighted by metacell sizes.

VlnPlot.SuperCell(bm.mc.multi,features = c("CD19","CD14","GNLY","CD34","FLT3","CD3G"),group.by = "celltype.l1",
                  ncol = 3)
