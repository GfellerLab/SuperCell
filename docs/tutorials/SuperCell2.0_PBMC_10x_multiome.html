1.2 Load PBMC 10x multiome datasets

PBMC 10x multiome data were generated by 10x genomics and finely annotated in Hao et al., 2021.

First we have to download the ATAC fragment file for this dataset from 10X website. This can take few minutes (2.2 GB)

dir.create("./PBMC_10Xmultiome/fragments/",recursive = T)

url.fragment.file <- "https://cf.10xgenomics.com/samples/cell-arc/2.0.0/pbmc_granulocyte_sorted_10k/pbmc_granulocyte_sorted_10k_atac_fragments.tsv.gz"

if (!file.exists(dest.fragment.file)) {
  options(timeout = 600)  
  download.file(url, dest.fragment.file = dest, mode = "wb")
}

We also need the corresponding index file.

dest.index.file <- "./PBMC_10Xmultiome/fragments/pbmc_granulocyte_sorted_10k_atac_fragments.tsv.gz.tbi"

if (!file.exists(dest.index.file)) {

2 Single-cell preprocessing

2.1 Peak calling with MACS2 (optional)

The seurat object contains broad peaks. In this tutorial, as in SuperCell2.0 manuscript we propose to call narrow peaks with MACS2. Narrow peaks are expected to be better for TF motif analysis. This step is optional, we can skip it and follow the tutorial using the default broad peaks in the seurat object.

You need to have macs2 installed. Unfortunately it can’t be installed in the same conda env with SuperCell/Seurat. Here we retrieve macs2 from our path.

macs2.path <- Sys.which("macs2")

Then we can use the CallPeaks Signac function.

DefaultAssay(pbmc) <- "ATAC"
pbmc[["ATAC"]] <- subset(pbmc[["ATAC"]] , features = rownames(pbmc[["ATAC"]] )[1:2]) #a trick to save memory as we are calling new peaks
gc()

peaks <- CallPeaks(
  object = pbmc,
  macs2.path = macs2.path,
  group.by = "seurat_annotations",
  additional.args = "--max-gap 50"
)

peaks <- keepStandardChromosomes(peaks, pruning.mode = "coarse")
peaks <- subsetByOverlaps(x = peaks, ranges = blacklist_hg38_unified, invert = TRUE) 

peak.counts <- FeatureMatrix(
  fragments = Fragments(pbmc),
  features = peaks,
  cells = colnames(pbmc)
)




pbmc[["ATAC"]] <- CreateChromatinAssay(
  counts = peak.counts,
  genome = 'hg38',
  min.cells = 1, 
  annotation=annotations,
  fragments = Fragments(pbmc)
)

remove(peak.counts)
gc()

2.2 Dimension reductions

Before identifying metacells we have to preprocess the single-cell data. This includes data normalization and dimension reduction of each modality. For this we can follow the SCTransform Seurat workflow for RNA and the LSI Signac workflow for ATAC as in SuperCell2.0 manuscript.


DefaultAssay(pbmc) <- "RNA"
options(future.globals.maxSize = 1.5 * 1024 ^ 3) 
pbmc <- SCTransform(pbmc, verbose = FALSE,conserve.memory = T) %>% RunPCA()

DefaultAssay(pbmc) <- "ATAC"

pbmc[["SCT"]] <- NULL #once we have the PCA we can discard the SCT assay

DefaultAssay(pbmc) <- "ATAC"
pbmc <- RunTFIDF(pbmc)
pbmc <- FindTopFeatures(pbmc, min.cutoff = "q0")
pbmc <- RunSVD(pbmc)

gc()
#>             used   (Mb) gc trigger   (Mb)  max used   (Mb)
#> Ncells  14874907  794.5   25207358 1346.3  25207358 1346.3
#> Vcells 351648823 2682.9  991463885 7564.3 843770026 6437.5

The fist compenent of lsi dimension reduction is correlated with sequencing depth of the ATAC modality. Thus, we discard it for metacell identification and downstream analysis.

DepthCor(pbmc)


rna.comp <- c(1:40) # components used from the dimension redcution of the RNA modality
atac.comp <- c(2:40) # components used from the dimension reduction of the ATAC modality

2.3 Single-cell multimodal integration (optional)

Based on these dimension reductions, we can integrate RNA and ATAC modalities together using the WNN approach from Seurat. This step is not required for metacell identification but we will use the single-cell final UMAP embedding to visually assess metacell quality.



pbmc <- FindMultiModalNeighbors(pbmc, 
                                reduction.list = list("pca", "lsi"), 
                                dims.list = list(rna.comp, atac.comp)
)

pbmc <- RunUMAP(pbmc, nn.name = "weighted.nn", 
                reduction.name = "wnn.umap", 
                reduction.key = "wnnUMAP_")

DimPlot(pbmc,group.by = "seurat_annotations")

3 Metacell identification with SuperCell2.0

3.1 Unsupervised multimodal metacell identification

We can identify metacells based RNA and ATAC modalities.

pbmc.mc.multi <- SCimplify_for_Seurat(
  pbmc, 
  assay = c("RNA","ATAC"),
  reduction = list("pca", "lsi"), 
  dims = list(rna.comp, atac.comp), 
  gamma = graining.level
)

SCimply_for_Seurat function gives a seurat metacell object with aggregated (summed) raw counts for each modality. All categorical metadata available in the single cell seurat object are also aggregated in the resulting metacell object by assigning the metacell to the label with the maximum absolute abundance within it.

4 Downstream analyses

4.1 Aggregating fragment file at the metacell level

Some downstream analyses for the ATAC modality require a fragment file. We can create one for our metacell seurat object using the membership vector and the AggregateFragmentFile function.

This aggregation can be multi-threaded by specifying a number of cores to use with the nb_cl arguments. This steps requires to have htslibn (bgzip, tabix) installed in your environment (which in the case in the conda env supercell_tuto_env we provide).


membership.vec <- paste0("Metacell_",pbmc.mc.multi@misc$membership)
names(membership.vec) <- names(pbmc.mc.multi@misc$membership)

mc.frag.path <- AggregateFragmentFile(input_file = dest.fragment.file,
                                      tmp_path = "./tmp/",
                                      nb_cl = 4, # number of cores to use
                                      output_path = "./PBMC_10Xmultiome/fragments/",
                                      membership = membership.vec)

4.2 Gene activities at the metacell level

Now that we have aggregated the fragment file at the metacell level we can compute gene activities (eg. gene body accessibility) in our metacells. We can do this for the top 4000 variable genes in the RNA modality.

DefaultAssay(pbmc.mc.multi) <- "RNA"
pbmc.mc.multi <- FindVariableFeatures(pbmc.mc.multi,nfeatures = 4000)

DefaultAssay(pbmc.mc.multi) <- "ATAC"

gene.activities <- GeneActivity(object = pbmc.mc.multi, 
                                assay = "ATAC",
                                features = VariableFeatures(pbmc.mc.multi[["RNA"]]))

pbmc.mc.multi[["ACTIVITY"]] <- CreateAssayObject(counts = gene.activities)
DefaultAssay(pbmc.mc.multi) <- "ACTIVITY"

pbmc.mc.multi <- NormalizeData(
  pbmc.mc.multi, assay = "ACTIVITY",
  normalization.method = "LogNormalize", 
  scale.factor = median(pbmc.mc.multi$nCount_ACTIVITY) 
)

Finally we can evaluate the correlation between gene activity and gene expression in our metacells for selected genes. For this we have to normalize the RNA assay in our metacells first.

DefaultAssay(pbmc.mc.multi) <- "RNA"
pbmc.mc.multi <- NormalizeData(pbmc.mc.multi)

We can now evalulate the intermodality feature correlation, for instance with TCF7 a TF of naive T cells.
